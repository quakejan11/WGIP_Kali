3. CORE FEATURES
================================================================================

3.1 Adapter Selection & Kismet Control
-------------------------------------------------------------------------------
- Dropdown list of available WiFi interfaces (wlan0, wlan1, etc.)
- Display adapter details: name, MAC address, mode, channel, status
- Start Kismet on selected adapter
- Stop Kismet
- Refresh status
- Remember last used adapter

3.2 Live Data Feed (PCAP Stream)
-------------------------------------------------------------------------------
- WebSocket connection to Kismet PCAP stream
- Real-time display of WiFi networks
- Columns: BSSID, ESSID, Channel, Signal, Security, Clients
- Signal strength color coding (Green/Yellow/Red)
- Auto-refresh every 2-3 seconds

3.3 Temp DB Fallback System
-------------------------------------------------------------------------------
- All PCAP data automatically saved to Temp DB
- 24-hour Time-To-Live (auto-cleanup)
- If PCAP stops for 30+ seconds → Auto-switch to Temp DB
- If PCAP resumes → Auto-switch back to Live
- Manual controls: Clear All, Clear Old (>24h), Export to .kismet
- Status indicator showing Live/Fallback mode

3.4 DeAuth Monitor (Sub Page)
-------------------------------------------------------------------------------
- Move existing DeAuthPage.tsx content here
- List active/stopped DeAuth attacks
- Start new attack with dialog (BSSID, Client, Channel)
- Stop running attacks
- Real-time updates

3.5 Signal Map (Sub Page)
-------------------------------------------------------------------------------
- Leaflet map integration
- Show detected BSSIDs as markers
- Signal strength circles
- Click marker → show device details
- Auto-update with new detections

4. BACKEND REQUIREMENTS
================================================================================

4.1 API Endpoints
-------------------------------------------------------------------------------
GET  /api/interfaces              → List available WiFi interfaces
POST /api/interfaces/select       → Select active interface
POST /api/kismet/start            → Start Kismet on selected interface
POST /api/kismet/stop             → Stop Kismet
GET  /api/kismet/status           → Check Kismet status
GET  /api/pcap/status             → PCAP health check (last packet, connected)
GET  /api/live/events             → Get events from Temp DB (fallback)
GET  /api/live/events/recent      → Get last N events
POST /api/live/clear              → Clear all Temp DB data
POST /api/live/clear-old          → Delete data older than X hours
GET  /api/live/export             → Export Temp DB data to .kismet
GET  /api/live/status             → Get Temp DB stats (count, oldest, newest)
WebSocket /ws/pcap-live           → PCAP live stream
WebSocket /ws/live-data           → Live data WebSocket

4.2 Database Schema (Temp DB - SQLite)
-------------------------------------------------------------------------------
Table: live_events

Column          Type           Description
-------------------------------------------------------------------------------
id              Integer        Primary Key
event_type      String(50)     bssid, client, packet, alert, etc.
timestamp       DateTime       When event occurred
data            JSON           Full event details
bssid           String(17)     Indexed
channel         Integer        WiFi channel
signal          Integer        Signal strength
essid           String         Network name
created_at      DateTime       When inserted to Temp DB
expires_at      DateTime       created_at + 24 hours

Indexes:
- bssid_idx (bssid)
- created_at_idx (created_at)

4.3 Background Jobs
-------------------------------------------------------------------------------
- Auto-cleanup every hour (delete records older than 24h)
- PCAP health check (monitor last packet timestamp)

6. DATA FLOW LOGIC
================================================================================

6.1 Normal Operation (PCAP Active)
-------------------------------------------------------------------------------
PCAP Stream → Display Live → Also Save to Temp DB (background)

Status: "🟢 Live PCAP - Connected"

6.2 PCAP Stops for 30s
-------------------------------------------------------------------------------
PCAP Stream → ❌ No data for 30s
→ Auto-detect timeout
→ Switch to Temp DB
→ Display from Temp DB

Status: "🟡 Fallback Mode - Using Temp DB (1,234 records)"

6.3 PCAP Resumes
-------------------------------------------------------------------------------
PCAP Stream → ✅ Data resumes
→ Auto-detect reconnection
→ Switch back to PCAP Live

Status: "🟢 Live PCAP - Connected"
